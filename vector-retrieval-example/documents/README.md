# Homework source corpus

Use the five complete PDFs supplied with HW-09, located in `../../documents/`
in the extracted materials package. The project rebuild command uses
`--source ../documents` when run from the project directory.

For a standalone checkout, obtain the same homework package and place its
`documents/` folder alongside the checkout, or pass its path via `--source`.
Do not commit PDFs to Git. The build validates filenames and page counts:

- fda-food-code-2026.pdf: 732 physical pages
- fda-employee-health-personal-hygiene-handbook.pdf: 45 pages
- fda-bad-bug-book-second-edition.pdf: 292 pages
- fda-appendix-3-bacterial-pathogen-growth-inactivation.pdf: 23 pages
- utah-risk-factor-study-2016-2017.pdf: 18 pages

Total: 1,110 pages. Three Food Code pages have no extractable text.
Use the complete PDFs rather than excerpts.
